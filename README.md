# Nilgiri House Website Clone 🏔️

A responsive and interactive web clone of the official **Nilgiri House** website for the IIT Madras BS Degree Program. 
## 🚀 Live Demo & Links

- **Live Site:** [https://alokraj002.github.io/Nilgiri-Clone-Website/]


## ✨ Features

- **House Overview:** Displays Nilgiri House's vision, mission, and student leadership details.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile viewing.
- **Events & Announcements:** Highlights upcoming house competitions, workshops, and meetups.
- **Resource Hub:** Quick access to essential links, guides, and study materials for IITM BS students.
- **Interactive UI:** Smooth scrolling, clean navigation, and accessible UI elements.


## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Icons & Styling:** FontAwesome / Google Fonts
- **Deployment:** GitHub Pages
